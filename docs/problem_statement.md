## Problem Statement

During CTF challenges and real-world assessments, source code hosted
on platforms like Gitea often becomes accessible either publicly or
after obtaining low-privilege credentials.

Manually reviewing large repositories during time-constrained
engagements is inefficient and error-prone.

The goal of this project is to design a tool that automates the
identification of security-relevant artifacts in Gitea repositories,
with an attacker-centric focus.
