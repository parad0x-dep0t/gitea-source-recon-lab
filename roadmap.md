# Project Roadmap

- Define attacker workflow
- Define detection categories and priorities
- Design rule engine and rule format

## Phase 1 – MVP Implementation
- Gitea repository enumeration (unauthenticated)
- File traversal and content fetching
- Regex-based detection (secrets, paths, endpoints)
- Console output

## Phase 2 – Advanced Detection
- Dependency analysis
- Language-aware rules
- Improved confidence scoring

## Phase 3 – Authenticated Gitea Access
- Login support
- Private repository enumeration

## Phase 4 – Attack Chain Correlation
- Cross-file correlation
- Exploit path suggestions
